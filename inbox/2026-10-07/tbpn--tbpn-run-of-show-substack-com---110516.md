How Long Until Someone Decompiles macOS?
Adobe got decompiled. [ https://substack.com/redirect/4a37228f-48ce-426f-9c45-005b2f3c2796?j=eyJ1IjoiMXlnZjcifQ.KOUIeBfeCRzhIwFnKXyQigR4j0VpF-SZzascYhSZunw ] The apps are full featured clones of the Adobe products many people have been using for years. There are still a bunch of questions about how copyright applies here, and I wouldn’t be surprised if these get squashed pretty quickly, but it’s clear that any piece of software can now be reverse engineered nearly instantly with modern models.
The OpenAI math results show a similar story of the crazy spike in intelligence we see around tasks that can be run in fully virtual environments. Here’s the official OpenAI post [ https://substack.com/redirect/b75b000e-033e-4c05-adf8-7715231584ff?j=eyJ1IjoiMXlnZjcifQ.KOUIeBfeCRzhIwFnKXyQigR4j0VpF-SZzascYhSZunw ] and a good analysis by Josh Ganz that I enjoyed [ https://substack.com/redirect/3d3a1146-64f5-4151-930e-29104875535e?j=eyJ1IjoiMXlnZjcifQ.KOUIeBfeCRzhIwFnKXyQigR4j0VpF-SZzascYhSZunw ] reading about it.
François Chollet, creator of ARC-AGI, broke down a theory of what this big jump in progress means for overall AGI progress and how these advancements generalize:
It definitely feels like a superintelligence to me. No human intelligence has been able to solve this many math problems at this level of difficulty in history, so it’s clearly something new. Terminology debates aside, there are some near term impacts that are worth working through.
Ben Thompson has been working through some macOS frustrations while he goes deeper into agentic AI, from Apple and a Hacker’s Future [ https://substack.com/redirect/f7fe9b69-c764-4c6a-9209-039435411638?j=eyJ1IjoiMXlnZjcifQ.KOUIeBfeCRzhIwFnKXyQigR4j0VpF-SZzascYhSZunw ], he writes:
What I’m much more interested in is controlling the software layer myself. The fact of the matter is that with AI you can decompile almost all existing software — there is a revolution happening in gaming over the past few weeks, as game after game is decompiled to source and ported to any platform you wish — and you can write your own. That means my software that interacts with my agent in the way I want it to for everything; that’s way more exciting than praying Apple delivers the right API and that 3rd-party developers don’t suck.
There’s an obvious bullcase for Linux broadly, and on the desktop here, but I’m increasingly wondering if we might just see a full decompile of macOS hit the timeline. Don’t like that security features don’t automatically install? Patch that yourself. Don’t like that every new application you vibecode needs to be granted permissions via UI pop-ups? Change that behavior in a single prompt.
This actually feels like it could be good for the hacker’s future in the Apple ecosystem, although it calls into question a whole bunch of other issues with this new world where software is infinitely malleable. Regardless, it’s firmly the domain of hackers for the time being, so it will be fun to watch the open-source community duke it out with tech companies over where the new line is exactly.
